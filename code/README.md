# UrbanMove

## Apps

### "users/"

- [] Registrar o consultar un usuario.
- [] Ver bicicletas o patinetes disponibles por zona.
- [] Crear, confirmar o cancelar una reserva.
- [] Iniciar el uso de un recurso reservado o disponible.
- [] Finalizar el viaje indicando zona de destino.
- [] Consultar el historial personal de reservas y viajes.

### "management/"

- [] Consultar recursos con batería baja, avería o uso anómalo.
- [] Retirar un recurso de disponibilidad pública.
- [] Registrar tareas de recarga, reparación o revisión.
- [] Volver a poner un recurso en servicio.
- [] Registrar la compra o incorporación de nuevos recursos.
- [] Consultar órdenes de recolocación generadas por el sistema.
- [] Marcar una orden de recolocación como asignada, en curso o completada.

### "business/"

- [] Recursos disponibles, reservados, en uso, en carga, en reparación y retirados.
- [] Reservas y viajes por franja horaria, zona y tipo de recurso.
- [] Zonas con déficit o exceso de bicicletas y patinetes.
- [] Órdenes de mantenimiento y recolocación abiertas, en curso y completadas.
- [] Indicadores de salud del sistema: servicios activos, errores recientes o eventos fallidos.
